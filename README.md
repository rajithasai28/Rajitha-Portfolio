
# Rajitha Sai — Robotics & AI Portfolio

A responsive React portfolio with a profile-based chatbot.

## Features

- About Me
- Skills
- Projects
- Experience
- Achievements
- Certifications
- Contact
- Resume download
- Profile chatbot
- Responsive dark robotics/AI design

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Before submitting

1. Add your real `resume.pdf` to `public/`.
2. Replace the placeholder GitHub, LinkedIn, Instagram and email values in `src/App.jsx`.
3. Replace project `#` links with real project/GitHub links.
4. Run `npm run build` and make sure it succeeds.
5. Push the complete project to a public GitHub repository.
